# Web font licences

Cormorant Garamond and Manrope are bundled by Next's font pipeline and served from this site's own origin. Both use the SIL Open Font License 1.1. The original notices and licence text are retained beside this file.

Sources retrieved 18 October 2026:

- https://raw.githubusercontent.com/google/fonts/main/ofl/cormorantgaramond/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt

Normal and genuine italic Cormorant faces are requested explicitly. The site does not rely on synthesised italic display lettering or on Google Fonts requests in the visitor's browser.
